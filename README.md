# Amine Nfissi — Developer Quest

Portfolio interactif en HTML, CSS et JavaScript pur. Aucun Node.js requis.

## Lancer
Ouvre `index.html` dans un navigateur, ou utilise Live Server dans VS Code.
Les polices (Google Fonts) nécessitent une connexion ; sinon des polices système prennent le relais.

## Structure
- `index.html` : contenu et structure des 7 niveaux
- `css/style.css` : thème (couleurs nommées en haut du fichier, variables `:root`)
- `js/script.js` : XP, niveaux, badges, terminal
- `assets/images/ma-photo.jpeg` : ta photo (remplace le fichier pour la changer)

## Le jeu
Chaque niveau découvert rapporte 100 XP, chaque badge 25 XP, le terminal 50 XP (1000 XP au total).
La carte (bouton Map ou EXPLORE) permet de sauter d'un niveau à l'autre.
